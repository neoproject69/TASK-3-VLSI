# TASK-3-VLSI

## Sequential Circuits using Verilog HDL

This repository contains the Verilog HDL implementation, testbench files, simulation results, and report for Task-3 of the VLSI Internship.

## Contents

### 📁 Verilog_Source_Files
Contains the Verilog HDL source code for:
- 4-bit Register
- 4-bit Binary Counter
- D Flip-Flop
- JK Flip-Flop

### 📁 Testbench_Files
Contains the testbench programs used to verify the functionality of each sequential circuit.

### 📁 Simulation_Screenshots
Contains GTKWave simulation output screenshots for all implemented circuits.

### 📁 Report
Contains the Task-3 report documenting the implementation, simulation procedure, waveform analysis, and observations.

## Tools Used

- Verilog HDL
- Icarus Verilog (iverilog)
- GTKWave
- GitHub

## Circuits Implemented

- D Flip-Flop
- JK Flip-Flop
- 4-bit Register
- 4-bit Binary Counter
